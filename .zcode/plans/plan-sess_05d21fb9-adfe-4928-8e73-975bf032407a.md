# Рефакторинг UI: Glassmorphism + светлая/тёмная тема + библиотека UI-компонентов

## Дизайн-система

**Стеклянная эстетика на CSS-переменных (дизайн-токенах)** — вся палитра, радиусы, тени и степень размытия описываются токенами в `:root`, тёмная тема переопределяет их через `[data-theme='dark']`. Переключение темы мгновенное, без перезагрузки.

- Фон: живой градиент-мешь (несколько наложенных radial-gradient'ов, лёгкая CSS-анимация дрейфа пятен)
- Карточки: полупрозрачное стекло `rgba + backdrop-filter: blur(20px)`, тонкая светлая рамка
- Акценты: белые/градиентные кнопки в светлой теме, фиолетово-розовое свечение в тёмной
- Тема по умолчанию — светлая; переключатель ☀️/🌙 в шапке, выбор сохраняется в localStorage

## Библиотека UI-компонентов — новый `src/app/ui/`

Все standalone, настраиваются через `inputs`, форм-контролы реализуют `ControlValueAccessor` (совместимы с текущим `ngModel`):

| Компонент | Варианты/настройки |
|---|---|
| `UiButton` | variant: primary / glass / danger / ghost; size: md / sm; disabled; full width |
| `UiIconButton` | круглая иконка-кнопка (стрелки карусели, ✓/✕) |
| `UiInput`, `UiTextarea`, `UiSelect` | label, placeholder, ошибка/подсказка, CVA |
| `UiCheckbox` | CVA, используется в конструкторе и ролях |
| `UiBadge` | тон: neutral / accent / success / danger (роли, категории) |
| `UiCard` | стеклянный контейнер (карточки товаров, формы) |
| `UiEmptyState` | иконка + текст («Товаров пока нет», «Новых заявок нет») |
| `UiSpinner` | индикатор загрузки (страница товара, профиль) |

## ThemeService — `src/app/core/theme.service.ts`

Сигнал текущей темы, инициализация из localStorage (fallback: системная), применение через `data-theme` на `<html>`, метод `toggle()`.

## Рефакторинг страниц (весь существующий функционал сохраняется)

- **Шапка**: стеклянный хедер с blur, кнопка смены темы
- **Главная**: стеклянные карточки товаров с hover-подъёмом
- **Авторизация, профиль, пользователи, форма товара**: стеклянные панели, новые поля и кнопки; таблицы — стеклянные с полупрозрачными строками
- **Карточка товара**: карусель в стеклянной рамке, стеклянные стрелки и точки, селекторы конфигурации
- Все текущие Less-стили страниц переводятся на токены
