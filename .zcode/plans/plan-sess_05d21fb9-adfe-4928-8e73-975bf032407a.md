# Система ролей: Админ, Модератор, Продавец, Покупатель

## Модель
- Роли хранятся в `users/{uid}`: `roles: { seller: boolean, moderator: boolean }` — пересекаются, выставляются чекбоксами
- **Покупатель** — неявная роль по умолчанию (любой авторизованный), чекбокса не требует
- **Админ** — единственный, определяется по email `vit@mail.ru` (константа в `environment.ts`), чекбокс не нужен
- Легаси-поле `isSeller` остаётся поддержкой для уже созданных профилей: `isSeller = roles.seller || isSeller`

## Изменения

**1. `environment.ts`** — константа `adminEmail: 'vit@mail.ru'`.

**2. `models.ts`** — `UserProfile` получает `roles?: { seller?: boolean; moderator?: boolean }`.

**3. `auth.service.ts`** — сигналы `isSeller` (с учётом легаси), `isModerator`, `isAdmin` (по email). Самостоятельный `setSeller` убирается — роли теперь назначает админ.

**4. Страница «Пользователи»** — новая `pages/users/`, маршрут `/users`:
- Список всех пользователей из коллекции `users` (email + текущие роли)
- Чекбоксы «Продавец» и «Модератор» напротив каждого — админ может включать/выключать (независимо друг от друга)
- Страница доступна только админу: новый `adminGuard` (+ ссылка в шапке только для админа; не-админа по прямому URL перебрасывает на главную)

**5. Профиль** — вместо чекбокса «Я продавец» (самоназначение уходит, роли теперь даёт админ) — бейджи ваших ролей: Админ / Модератор / Продавец / Покупатель.

**6. `firestore.rules`**:
- `users`: читать все — админу, свой — себе; обновлять свой профиль — можно, но нельзя менять себе `roles`/`isSeller` (защита от самоповышения); админ может менять роли любому
- `products`: публиковать может владелец с `roles.seller == true` или легаси `isSeller == true`
