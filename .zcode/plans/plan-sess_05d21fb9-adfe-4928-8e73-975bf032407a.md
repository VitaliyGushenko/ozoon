# Стартовая страница маркетплейса с авторизацией и товарами

## Модель данных (Firestore)
- `users/{uid}`: `{ email, isSeller: boolean, createdAt }` — профиль, флаг продавца
- `products/{id}`: `{ title, description, imageUrl, sellerUid, createdAt }` — товары

## Изменения в коде

**1. Подключение сервисов Firebase** — `src/app/app.config.ts`
Добавить `provideAuth(() => getAuth())` и `provideFirestore(() => getFirestore())`.

**2. Модели** — новый `src/app/core/models.ts`
Интерфейсы `UserProfile` и `Product`.

**3. AuthService** — новый `src/app/core/auth.service.ts`
- Текущий пользователь (`user` signal из `onAuthStateChanged`)
- Профиль из Firestore (`profile` signal, подписка на `users/{uid}`)
- Регистрация (`createUserWithEmailAndPassword` + создание документа профиля с `isSeller: false`)
- Вход, выход
- Переключение флага продавца (`setSeller(bool)` через `updateDoc`/`setDoc`)

**4. ProductsService** — новый `src/app/core/products.service.ts`
- Поток товаров (`collectionData` по `products`, сортировка по `createdAt`)
- Добавление товара (`addProduct`) — пишет `sellerUid` текущего пользователя

**5. Guard продавца** — новый `src/app/core/seller.guard.ts`
Функциональный guard: пускает на страницу добавления товара только если `isSeller: true`.

**6. Страницы** (standalone-компоненты в `src/app/pages/`)
- `home/` — главная: сетка карточек товаров (изображение, название, описание) на чистом CSS. Пустое состояние «товаров пока нет»
- `auth/` — вход и регистрация на одной странице (переключатель режимов), сообщения об ошибках Firebase
- `profile/` — email пользователя, чекбокс «Я продавец» (сохраняется в Firestore), кнопка выхода
- `add-product/` — форма: название, описание, URL изображения; доступна только продавцам (guard)

**7. Роутинг** — `src/app/app.routes.ts`
- `/` → Home, `/auth` → Auth, `/profile` → Profile (только для авторизованных), `/add-product` → AddProduct (guard продавца)
- `CanActivateFn` на профиль, редирект неавторизованных на `/auth`

**8. Каркас приложения** — `app.component.html/ts` (заменить заглушку Angular на хедер с навигацией: логотип, «Главная», «Добавить товар» (видна продавцам), «Профиль»/«Войти») + глобальные стили в `src/styles.less`.

**9. Правила безопасности** — новый `firestore.rules` + инструкция
- Товары: читать всем, писать только авторизованным продавцам (`get(users/$uid).data.isSeller == true`)
- Профили: читать/писать только своему документу

## Что потребуется сделать вручную в консоли Firebase (я дам пошаговую инструкцию)
1. Authentication → включить провайдер Email/Password
2. Firestore Database → создать базу
3. Вставить правила из `firestore.rules`

## Проверка
`ng build` + запуск `ng serve`, проверка в браузере: регистрация, включение флага продавца, добавление товара, отображение на главной.
